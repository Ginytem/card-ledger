部署与配置说明
1. 登录账号密码
在 wrangler.toml 中配置 USERNAME 和 PASSWORD，演示环境：免登录，数据仅存本浏览器；正式部署说明见 GitHub 仓库 README。
2. 微信推送（PushPlus）
演示环境：推送为本地模拟，无需配置，在线上 Secret 中配置 PUSHPLUS_TOKEN，然后重启服务。改完后点上方「发送测试提醒」验证，微信能收到消息即配置成功。
3. 邮件提醒（可选）
将 wrangler.toml 的 PUSHPLUS_API 改为你使用的邮件/通知接口地址（支持 JSON：token, title, content），即走邮件通道。
4. 每日自动提醒（上线后）
部署到 Cloudflare Workers 后，在 Worker 设置里添加 Cron 定时触发器（如 0 1 * * *，北京时间每天 9 点）。还款提醒提前天数、年费提前 60 天提醒由定时任务每天检查，同一提醒不会重复发送。
本地调试不跑定时任务，用上方「发送测试提醒」验证通道。
